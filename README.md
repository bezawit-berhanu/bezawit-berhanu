## 🚀 Projects

### Dormitory Management System
A full-stack dormitory management platform designed to digitize student accommodation processes and dormitory operations.

- Developed the backend using ASP.NET Core and Clean Architecture.
- Worked on REST APIs, database integration, JWT authentication, and role-based access control.
- Used Entity Framework Core and TiDB/MySQL for data persistence.
- Built the frontend using React and TypeScript.
- Integrated real-time communication using SignalR.

**Tech:** C#, .NET, ASP.NET Core, EF Core, React, TypeScript, MySQL/TiDB, SignalR.

### Sina Dental Customer Information Management Platform (SCDCIMP)
A dental clinic management platform for handling patient information, appointments, dental procedures, financial records, and clinic operations.

- Designed a modular backend structure using Clean Architecture.
- Developed the backend foundation using Node.js and Express.js.
- Designed relational data models using Prisma ORM.
- Worked on authentication, role-based access control, and frontend-backend integration.

**Tech:** JavaScript, Node.js, Express.js, React, Prisma ORM, TiDB/MySQL, Axios.
